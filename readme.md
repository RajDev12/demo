# 🧠 Support Vector Machine (SVM) Classifier

A comprehensive Python implementation of Support Vector Machines (SVM) for binary and multi-class classification tasks. Designed for learners, educators, and practitioners to explore SVMs with hands-on examples and modular code.

## 📦 Features

- ✅ Custom implementation using scikit-learn
- 📊 Decision boundary visualizations
- 🔍 Kernel support: Linear, Polynomial, RBF
- 🧪 Train/test split and cross-validation
- 📁 Modular code for easy reuse
- 🧠 Educational demos for classroom use

## 🧰 Technologies Used

- Python 3.8+
- NumPy
- pandas
- scikit-learn
- matplotlib / seaborn
